## Грабли

- `nohup … &` вместе с `run_in_background: true` убивает процесс: снимки гонять
  в foreground с `timeout: 420000`.
- Липкая шапка ложилась поперёк каждого снимка блока — лечится `hideOverlays()`
  до `shootSections()` (скрывает всё `fixed`/`sticky`), для героя не применять.
- ImageMagick на маке нет. Есть `sips` и Pillow 11.3.0. **`sips -Z 1500` расплющивает
  длинные страницы в ленточки по 22 px** — длинные скриншоты резать только Pillow
  (готовый нарезчик — в истории сессии, результат в `img/strip/`).
- `codex exec --output-schema` в foreground упирается в лимит 120 с (exit 144).
  Перепроверить через `nohup` и замерить время ответа: окно моста 270 с.
