# Звонки отдела продаж RaxPro — сырьё для аватаров

Источник: ProAudit, https://raxprouzsalesai.asosit.uz/audio (аккаунт Умида, U52236).
Выгружено 20.08.2026 через API `/api/audio` (read-only, ничего в платформе не менялось).

## Что здесь
- `transcripts.md` — пять полных расшифровок с таймкодами и разметкой Mijoz / Menejer
- `analysis.md` — разбор ИИ по каждому звонку: оценка, качество лида, ошибки, критерии

## Важно про объём
В аккаунте на момент выгрузки **всего 5 звонков**, не 30–40.
`/api/audio?limit=100` возвращает `total=5`, интерфейс подтверждает: «5 / 5 ta koʻrsatildi».
Фильтры ни при чём — проверено запросом без параметров.

Звонки тянутся из Bitrix, в интерфейсе есть кнопка «Sinxron». В рейтинге видно
6 менеджеров и 10 продаж, но `callsCount = 0` — то есть в систему залито
далеко не всё, что есть в CRM.
